# ============================================================================
# 镜像同步清单
# ============================================================================
#
# 本文件配合 .github/workflows/sync-images-batch.yml 使用。
# 在 Actions 页面手动触发该工作流，即可一次性同步下面列出的全部镜像，
# 不必再一个个填表单。
#
# 语法：
#   - 每行一个镜像，必须带 tag 或 digest
#   - 井号开头是整行注释，行尾也可以写注释
#   - 空行会被忽略
#   - 不需要写 docker:// 前缀
#
# 适用场景：
#   维护一套固定的镜像集合（比如某个 Kubernetes 版本的组件、某套中间件栈），
#   需要定期跟着上游更新，同时保证国内集群随时拉得到。
#
